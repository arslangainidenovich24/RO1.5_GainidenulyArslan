Esports Academy - Final Project

This project is a database for managing an Esports Academy (teams, players, sponsors, and tournaments).

Project Information:
Database Name: esports_academy_db
Software: PostgreSQL / DBeaver
Done by: [Gainidenovich_Arslan]


Files in folder:
1.01_model.png - Database diagram from Lucidchart.
2.02_final.sql - SQL script to create tables and insert data.
3.README.md - Short information about the project (this file).


How to run the code:

1.Open DBeaver.
2.Create a new database: `CREATE DATABASE esports_academy_db;`
3.Connect to the new database.
4.Open `02_final.sql` and copy the code to the SQL editor.
5.Press Ctrl + A to select all code, then press Alt + X to run it.

The script drops old tables and roles if they exist, then creates everything new without errors.
